# 学习库（vault）：结构、格式、节奏

学习库是**用户自己的资产**：本地纯文本（Markdown + CSV），换任何 AI 工具都能接着用。
**不要把学习库推到公开仓库**，里面是个人数据。

## 结构（三层）
```
vault/
├─ 00-我/                    # 个人模型，跨目标、长期更新
│  ├─ 画像.md                # 稳定层：价值观、优势（附证据）、长期约束
│  ├─ 当前处境.md            # 状态层：阶段、目标、时间、预算、截止日期
│  ├─ 学习说明书.md          # 规则层：对这个人有效的方法（每条都要附证据），AI 每次开始必读
│  └─ 决策日志.md            # 决定、理由、预期、结果
├─ 01-能力地图.md            # 已掌握的条目及外部证据，跨目标复用
├─ 02-目标/<日期_目标名>/    # 每个目标一个文件夹：计划、评价标准、诊断、复盘
├─ data/                     # 原始层：只追加，不修改
│  ├─ attempts.csv
│  ├─ sessions.csv
│  └─ feedback.csv           # 外部验证记录
├─ notes/                    # 用户自己写的笔记（标注核实状态）
└─ library/                  # 可复用资源：评价标准、可信来源、经验库
```
**原则**：原始数据（data/）只追加、不修改；结论（能力地图、复盘）随时可以从原始数据重新生成。这样一次总结写错，不会污染整个资产。

## 文件格式

### data/attempts.csv（每道题一行）
| 列 | 填写 |
|---|---|
| 日期 | 2026-01-31 |
| 目标 | 目标文件夹名 |
| 条目 | 阶段 1 拆出的条目名（知识点 / 子技能 / 任务） |
| 题目 | 简述，或题号 |
| 作答 | 用户的原始作答要点（保留过程，不只是答案） |
| 结果 | 对 / 错 / 部分（或 0–1 之间的分数） |
| 把握度 | 作答**之前**报的 0–100 |
| 用时秒 | 可空 |
| 错因 | 概念不懂 / 步骤错 / 没读清题 / 粗心 / 会但说不清 / 迁移失败（对了就留空） |
| 题目来源 | AI出题 / 真题 / 外部测验 |

`题目来源` 很重要：统计时会把"AI 出题"和"真题、外部测验"分开算，后者才是证据。

### data/sessions.csv
`日期,目标,模式,分钟,完成内容,状态(1-5),备注`

### data/feedback.csv（外部验证）
`日期,目标,验证方式,评价人或来源,结果,证据链接,结论`

### 学习说明书.md 的规则格式
```
- 规则：先举例、后讲定义
  证据：第 3 周对比，留出题正确率 58% → 76%（data/attempts.csv）
  日期：2026-03-02　复验日期：2026-06-02
```
没有证据的偏好可以记，但要写"未验证"，不能当规则用。

### notes/ 里每条笔记的文件头
```
---
状态: 已核实 / 待核实 / AI生成未核实
来源: 链接或出处
---
```

## 节奏
| 时机 | 做什么 |
|---|---|
| 每次开始 | 读学习说明书、当前处境、计划、到期复习，用一句话说出今天做什么 |
| 每次结束 | 追加 attempts.csv 和 sessions.csv |
| 每周 | 运行 `scripts/learn_stats.py`；对照计划和止损条件；提出学习说明书的修改（附证据，用户批准后写入） |
| 每月 | 一次延迟测验（隔 1 个月重测已学内容）；清理长期没用的笔记；检查到期需要复验的规则 |
| 每季度 | 职业或方向复盘：方向还对吗？ |

## 阶段转换（达到里程碑时）
1. **复盘**：哪些方法有效、哪些决定对了或错了，写入学习说明书和决策日志
2. **更新能力地图**：把有外部证据的条目记进 `01-能力地图.md`，以后的诊断直接跳过
3. **处境更新**：只问 3 个问题，不重新建档
4. **下一阶段**：给出 2–3 个选项和各自的取舍，用户决定，记入决策日志

## 越用越顺手的机制
- 新目标的诊断先查能力地图，已有证据的条目跳过
- 评价标准、可信来源、经验库直接复用
- 学习说明书里的规则让讲解方式、练习难度、时长自动适配这个人
- 换 AI 工具时，读学习库 5 分钟内就能接着学（可迁移测试）
