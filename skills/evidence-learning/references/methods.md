# 方法库

## 一、按知识类型选练习方法
| 知识类型 | 例子 | 主要方法 |
|---|---|---|
| 事实、概念 | 单词、公式、定义、术语 | 主动回忆 + 间隔复习 |
| 解题步骤 | 数学、编程、会计分录 | 先看完整例题 → 补全式练习 → 独立做 → 不同题型交错 |
| 动作、感知 | 乐器、运动、发音、绘画 | 刻意练习 + 录下来对照 + 专家点评 |
| 判断、经验 | 写作、运营、设计、管理 | 案例分析 + 真实产出 + 懂行的人点评 |

一个目标通常混合多种类型，按阶段 1 拆出的条目逐条判断。

## 二、方法清单（标准名称，方便自己搜）
「确定」= 有大量研究或广泛使用；「不太确定」= 效果因人因场景差异大，或者具体做法版本多。

### 学习科学
| 方法 | 英文 | 一句话 | 确定性 |
|---|---|---|---|
| 主动回忆 / 测试效应 | Retrieval Practice / Testing Effect | 自己从记忆里提取，比反复看效果好 | 确定 |
| 间隔复习 | Spaced Repetition | 间隔逐渐拉长的复习；Anki 的 FSRS 算法会按个人记录调整间隔 | 确定 |
| 交错练习 | Interleaving | 不同题型混在一起练，提高辨别"该用哪种方法"的能力 | 确定 |
| 例题效应 / 渐退例题 | Worked Example Effect / Faded Examples | 新手先看完整例题，再逐步撤掉步骤自己补 | 确定 |
| 刻意练习 | Deliberate Practice（Ericsson） | 明确的小目标 + 即时反馈 + 略高于当前水平 | 确定 |
| 必要难度 | Desirable Difficulties（Bjork） | 练习时有点吃力，长期效果反而更好 | 确定 |
| 自我解释 | Self-Explanation | 用自己的话解释"为什么"，比只记结论好 | 确定 |
| 校准 | Calibration / Metacognitive Monitoring | 对比把握度和实际正确率，纠正"以为自己会了" | 确定 |

### 课程和目标设计
| 方法 | 英文 | 一句话 | 确定性 |
|---|---|---|---|
| 逆向设计 | Backward Design / Understanding by Design（Wiggins & McTighe） | 先定目标和证据，再设计学习活动 | 确定 |
| 布鲁姆分类法（修订版） | Revised Bloom's Taxonomy | 给目标定层级：记忆 → 理解 → 应用 → 分析 → 评价 → 创造 | 确定 |
| 4C/ID 模型 | Four-Component Instructional Design（van Merriënboer） | 复杂技能用完整任务由简到繁地练，辅助逐步撤掉 | 确定 |
| 职业 / 任务分析 | DACUM / Job Task Analysis | 把岗位拆成具体任务和标准 | 确定 |
| 认知任务分析 | Cognitive Task Analysis / Critical Decision Method | 访谈专家，挖出"说不出口"的判断方式 | 确定 |

### 评价和验证
| 方法 | 英文 | 一句话 | 确定性 |
|---|---|---|---|
| 分级评分标准 | Analytic Rubric | 每一档写看得见的特征，不写"好 / 一般 / 差" | 确定 |
| 留出测验 | Held-out Test | 用从没练过的题检验，防止只是记住了答案 | 确定 |
| 评分一致性 | Cohen's Kappa | 两人独立评分，扣掉碰巧一致后的一致程度 | 确定 |
| 布里尔分数 | Brier Score | 衡量把握度预测准不准，越低越好 | 确定 |
| 单人对照实验 | N-of-1 Trial / Single-Case Design（ABAB） | 在自己身上轮流试两种方法，比较效果 | 确定（方法本身）；结论只适用于本人 |
| 结构化面试法 | STAR（Situation-Task-Action-Result） | 讲经历和准备面试的结构 | 确定 |

### 职业发展
| 方法 | 英文 | 一句话 | 确定性 |
|---|---|---|---|
| 前 90 天 | The First 90 Days（Watkins） | 新岗位的情境诊断、早期成果、期望对齐 | 确定 |
| 个人发展计划 | Individual Development Plan（IDP） | 按能力标准找差距，制定发展行动 | 确定 |
| 70-20-10 | 70-20-10 Model | 70% 靠工作实践、20% 靠他人、10% 靠课程 | 不太确定（经验比例，研究证据有限） |
| 决策日志 | Decision Journal（Annie Duke 等推广） | 记录决定时的理由和预期，事后对照结果 | 确定（做法）；效果因人而异 |
