# 方法库

## 一、按知识类型选练习方法
| 知识类型 | 例子 | 主要方法 |
|---|---|---|
| 事实、概念 | 单词、公式、定义、术语 | 主动回忆 + 间隔复习 + 阐述性追问 |
| 解题步骤 | 数学、编程、会计分录 | 先看完整例题 → 补全式练习 → 独立做 → 不同题型交错 |
| 动作、感知 | 乐器、运动、剪辑节奏、发音、绘画 | 首站最小闭环 + 刻意练习 + 录屏/成品对照 + 专家点评 |
| 判断、经验 | 写作、产品、运营、设计、管理 | 岗位任务链拆解 + 案例对比 + 真实产出交付 + 懂行者盲评 |

一个目标通常混合多种类型：先用**首站最小闭环**跑通一次完整微缩任务，再按阶段 1 拆出的条目逐条针对性训练。

## 二、方法清单（标准名称，方便自己搜）
「确定」= 有大量实证研究或行业广泛使用；「不太确定」= 效果因人因场景差异大，或者具体做法版本多。

### 学习科学与提问引导
| 方法 | 英文 | 一句话 | 确定性 |
|---|---|---|---|
| 主动回忆 / 测试效应 | Retrieval Practice / Testing Effect | 自己从记忆里提取，比反复重读看书有效得多 | 确定 |
| 间隔复习 | Spaced Repetition | 间隔逐渐拉长的复习；Anki 的 FSRS 算法可按个人记录动态调间隔 | 确定 |
| 交错练习 | Interleaving | 不同题型混在一起练，提高辨别"该用哪种方法"的能力 | 确定 |
| 例题效应 / 渐退例题 | Worked Example Effect / Faded Examples | 新手先看完整例题，再逐步撤掉步骤自己补全 | 确定 |
| 刻意练习 | Deliberate Practice（Ericsson） | 明确微目标 + 即时反馈 + 难度略高于当前舒适区 | 确定 |
| 必要难度 | Desirable Difficulties（Bjork） | 练习时适度吃力，长期保持与迁移效果反而更好 | 确定 |
| 自我解释 | Self-Explanation | 用自己的话解释"为什么这样对、那样错"，比只记结论好 | 确定 |
| 引导式提问 / 阐述性追问 | Guided Questioning / Elaborative Interrogation（King 等） | 提供高质量问题骨架（如"何时失效""与相似概念差在哪"），解决新手不知如何提问的盲区 | 确定 |
| 元认知校准 | Calibration / Metacognitive Monitoring | 作答前先报把握度并对比实际正确率，专治"看懂了以为自己会了" | 确定 |

### 课程、任务链与路线设计
| 方法 | 英文 | 一句话 | 确定性 |
|---|---|---|---|
| 逆向设计 | Backward Design / Understanding by Design（Wiggins & McTighe） | 先定终点目标和验收证据，再倒推学习活动 | 确定 |
| 4C/ID 复杂学习模型 | Four-Component Instructional Design（van Merriënboer） | 复杂技能先从最简完整任务（首站最小闭环）练起，由简到繁并逐步撤掉辅助 | 确定 |
| 布鲁姆分类法（修订版） | Revised Bloom's Taxonomy | 给目标定认知层级：记忆 → 理解 → 应用 → 分析 → 评价 → 创造 | 确定 |
| 职业与任务链分析 | DACUM / Job Task Analysis | 把岗位拆成"职能模块 → 具体动作链 → 输入/产出物 → 对接角色 → 能力项" | 确定 |
| 认知任务分析 | Cognitive Task Analysis / Critical Decision Method | 挖掘专家在模糊情境下"说不出口"的判断线索与避坑点 | 确定 |
| 概念图与状态路线图 | Concept Mapping / Mastery Knowledge Graph | 把零散节点连成依赖网络，并用不同颜色严格区分"练习态"与"外部已验证态" | 确定 |
| 计划谬误修正（时间对账） | Planning Fallacy Mitigation / Reference Class Forecasting | 给可用时间留出容错余量（如打 8 折）再与标准路径工时对账，防计划烂尾 | 确定 |

### 评价和外部验证
| 方法 | 英文 | 一句话 | 确定性 |
|---|---|---|---|
| 分级评分标准 | Analytic Rubric | 每一档写外行看得见的行为或成品特征，不写"好 / 一般 / 差" | 确定 |
| 留出测验 | Held-out Test | 用从未在练习中见过的真题或任务检验，防止只是背熟了答案 | 确定 |
| 评分一致性 | Cohen's Kappa | 两人独立评分，扣掉碰巧一致后的真实一致程度 | 确定 |
| 布里尔分数 | Brier Score | 衡量把握度预测准不准（0 最准，总瞎猜 50% 为 0.25） | 确定 |
| 单人对照实验 | N-of-1 Trial / Single-Case Design（ABAB） | 在自己身上轮流试两种学法，拿留出题正确率比效果 | 确定（方法本身）；结论只适用于本人 |
| 结构化复盘与面试表达 | STAR（Situation-Task-Action-Result） | 按情境—任务—行动—可验证结果组织作品复盘与面试回答 | 确定 |

### 职业发展与流程沉淀
| 方法 | 英文 | 一句话 | 确定性 |
|---|---|---|---|
| 前 90 天 | The First 90 Days（Watkins） | 新岗位的情境诊断、期望对齐、早期最小闭环成果 | 确定 |
| 个人发展计划 | Individual Development Plan（IDP） | 按岗位能力标准找真实差距，制定带截止日的发展行动 | 确定 |
| 决策日志 | Decision Journal（Annie Duke 等推广） | 记录选路线、换方法、止损时的理由和预期，事后对账 | 确定（做法）；效果因人而异 |
| 70-20-10 经验法则 | 70-20-10 Model | 70% 靠真实任务实践、20% 靠高人反馈、10% 靠看课读书 | 不太确定（经验比例，严格实证有限） |
